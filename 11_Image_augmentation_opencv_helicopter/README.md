# Image Augmentation using OpenCV - Helicopter Dataset

This notebook performs manual image augmentation using OpenCV on a helicopter image dataset.

## Objective

To implement and visualize augmentation techniques using OpenCV such as flipping, rotation, scaling, and affine transformations.

## Workflow

### 1. Setup
- Load helicopter image using OpenCV
- Display the original image

### 2. Augmentation Techniques
- Flip (horizontal and vertical)
- Rotate by custom angle
- Resize (scaling up/down)
- Apply affine transformation (shearing, translation)

### 3. Visualization
- Use `matplotlib` to plot before and after transformations

## Dependencies

- `opencv-python`
- `numpy`
- `matplotlib`

## Instructions

1. Clone this repository
2. Place helicopter image in the root directory
3. Run `11_Image_augmentation_opencv_helicopter.ipynb` step-by-step

## Output

- Transformed images using OpenCV routines
- Visual examples of augmentation pipelines
