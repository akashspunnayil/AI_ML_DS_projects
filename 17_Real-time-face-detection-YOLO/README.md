# Real-Time Face Detection using YOLO

This notebook uses YOLOv8 to perform real-time face detection via webcam input.

## Objective

To detect human faces in real-time using webcam stream and display bounding boxes using YOLOv8.

## Workflow

### 1. Webcam Access
- Capture real-time video using OpenCV

### 2. Model Inference
- Load YOLOv8 face detection model
- Run inference on live frames

### 3. Display Results
- Draw bounding boxes around detected faces
- Option to save video output

## Dependencies

- `ultralytics`
- `opencv-python`
- `matplotlib`

## Instructions

1. Run `17_Real-time-face-detection-YOLO.ipynb`
2. Allow webcam access
3. View live detection with bounding boxes

## Output

- Real-time video with face detection overlays
