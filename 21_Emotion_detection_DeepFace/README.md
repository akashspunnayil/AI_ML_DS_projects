# Emotion Detection using DeepFace (CUDA and Non-CUDA Versions)

This project implements an emotion detection pipeline using the `DeepFace` library and visualizes emotion probabilities for a given face image. It supports:

- A **CUDA/Colab version** that performs full inference using GPU.
- A **non-CUDA version** that uses pre-generated `.pkl` output for fast local inference.

---

## 📌 Project Highlights

- Detects facial emotions from an image.
- Extracts and displays confidence levels for 7 standard emotions.
- Visualizes both the face and corresponding emotion probabilities.
- Uses cleaned `.pkl` output for compatibility with local (CPU-only) systems.

## 🚀 Version 1: CUDA / Colab-Based Execution

This version performs full DeepFace inference and saves cleaned emotion predictions.

**Steps:**

1. Set `img_path` to your test face image.
2. Run the DeepFace emotion analyzer:

```python
analysis = DeepFace.analyze(img_path=img_path, actions=["emotion"], enforce_detection=True)[0]
```

3. Clean the output to remove `numpy` types using a recursive `deep_convert()` function.

4. Save the cleaned result as `emotion_analysis_cleaned.pkl`.

5. Visualize:

   * Original image with predicted emotion.
   * Bar plot of confidence levels for each emotion.

**Output Sample:**

```
dominant_emotion: angry
  angry: 92.84%
  happy: 1.54%
  neutral: 1.22%
  ...
```

## ❄️ Version 2: Non-CUDA / CPU-Only Execution

This version loads and visualizes results using `.pkl` generated by the Colab version.

**Steps:**

1. Place the following files in the working directory:

   * `emotion_analysis_cleaned.pkl`
   * The original test image (e.g., `angry_face_1.jpg`)

2. Load the pickle:

```python
with open("emotion_analysis_cleaned.pkl", "rb") as f:
    analysis = pickle.load(f)
```

3. Visualize:

   * Dominant emotion in the title of the image.
   * Bar chart of emotion probabilities.

---

## 🧠 Why Two Versions?

| Feature          | CUDA / Colab Version          | Non-CUDA Version         |
| ---------------- | ----------------------------- | ------------------------ |
| Inference Method | DeepFace live analysis        | Precomputed `.pkl` file  |
| GPU Dependency   | Yes                           | No                       |
| Use Case         | Training or one-time analysis | Repeated lightweight use |
| Output Saved     | Cleaned `.pkl` object         | Reused locally           |

## ⚠️ Notes

* `enforce_detection=True` ensures DeepFace analyzes only if a face is found.
* Cleaning the result removes NumPy objects for compatibility with pickle.
* The test image must match the one used to generate the `.pkl`.
